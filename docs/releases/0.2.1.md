# Warframe Companion 0.2.1

- Compare your last two confirmed inventories and see how many copies of a weapon to keep for crafting.
- Record a relic reward pick or a finished build. The companion keeps it pending for that account until a confirmed inventory sync covers it.
- See which Duviri Cave offers match your farming board and when the Circuit resets.
- On Windows, choose the installer, an extracted portable folder, or a single executable. Screen recognition is a separate, optional download in Settings.

### Updating on Windows

Close the companion and run the new installer, or replace the executable if you use the single-file edition. Keep the adjacent `data` folder when updating an existing portable profile. The Windows editions require the x64 .NET 10 and ASP.NET Core 10 shared runtimes and WebView2.
